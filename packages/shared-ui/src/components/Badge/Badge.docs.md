# Badge

## Usage

Non-interactive status pill (`26px` height) built from the Design System chip token sets (`success`, `warning`, `error`, `info`, `progress`).

## Required props

- `children`

## Accessibility notes

- Always include clear status text; never rely on color alone.

## Example

```tsx
<Badge tone="success">Verified</Badge>
<Badge tone="progress">In progress</Badge>
```
